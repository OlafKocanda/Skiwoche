# Skiwochen-Planer

Gemeinsame Planung der Skiwoche im März 2027 für Joni, Achim, Adrian und Olaf: Rangliste, Karte, Swipen und Abstimmung über 38 Alpen-Skigebiete.

- `index.html`: die komplette App, online unter https://olafkocanda.github.io/skiwoche/
- `database.rules.json`: Regeln für die Firebase Realtime Database (in der Firebase-Konsole unter „Regeln“ einfügen)

Die Stimmen liegen in der Firebase Realtime Database unter `skiwoche/`. Ohne Firebase-Konfiguration läuft die App nur lokal auf dem Gerät.
